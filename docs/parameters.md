# Design parameters

Every key in a design file, with its unit and default. Generated by
`volt2motion params --markdown`, so do not edit by hand.

See [the design file guide](design-file.md) for where each value comes from.

## top level

| Key | Default | Unit | Meaning |
|---|---|---|---|
| `name` | baseline |  | Design name, used for output file names. |

## motor

The motor. Per-phase values, star (wye) equivalent.

| Key | Default | Unit | Meaning |
|---|---|---|---|
| `motor.pole_pairs` | 7 |  | Magnet pole pairs, half the magnet count. A 12N14P motor has 7. |
| `motor.flux_linkage` | 0.008 | Wb | Magnet flux linkage at 20 C, phase peak. Sets torque per amp (Kt = 1.5 x pole_pairs x flux_linkage) and back-EMF. See the design file guide for converting Kv or Ke. |
| `motor.resistance` | 0.15 | ohm | Winding resistance per phase at 20 C. Half the line-to-line value. |
| `motor.ld` | 0.00012 | H | d-axis inductance per phase. Half the line-to-line value. Same as lq for surface-magnet motors. |
| `motor.lq` | 0.00012 | H | q-axis inductance per phase. Half the line-to-line value. |
| `motor.rotor_inertia` | 3e-05 | kg m^2 | Rotor inertia, from the datasheet or CAD. |
| `motor.copper_tempco` | 0.00393 | 1/K | Winding resistance rise per K. 0.00393 for copper. |
| `motor.magnet_tempco` | -0.0012 | 1/K | Flux change per K. About -0.0012 for NdFeB, -0.0003 for SmCo. |
| `motor.iron_loss_hyst` | 0.002 | W/(rad/s) | Hysteresis iron loss per rad/s of rotor speed. |
| `motor.iron_loss_eddy` | 1e-05 | W/(rad/s)^2 | Eddy current iron loss per (rad/s)^2 of rotor speed. |
| `motor.cogging_amp` | 0 | Nm | Cogging torque amplitude at the motor shaft. 0 turns it off. |
| `motor.cogging_periods` | 84 |  | Cogging cycles per rotor turn: the least common multiple of the slot and magnet counts (84 for 12N14P). |
| `motor.kt_curve_current` | [] | A | Optional FEA saturation curve: |iq| points. Leave empty for no saturation. |
| `motor.kt_curve_scale` | [] |  | Torque constant scale at each kt_curve_current point, 1.0 meaning no saturation. |

## driver

The motor driver PCB and its firmware.

| Key | Default | Unit | Meaning |
|---|---|---|---|
| `driver.pwm_freq` | 2e+04 | Hz | PWM frequency, also the current loop rate. |
| `driver.rds_on` | 0.004 | ohm | Series resistance per phase: MOSFET on-resistance plus copper plus the shunt's share. With rds_tempco 0 this is a fixed hot value. import-kicad sets the 25 C value and a tempco. |
| `driver.rds_tempco` | 0 | 1/K | Rise of rds_on per K of MOSFET temperature above 25 C. 0 keeps rds_on fixed. |
| `driver.switch_time` | 6e-08 | s | MOSFET rise plus fall time. Sets switching loss. |
| `driver.dead_time` | 3e-07 | s | Dead time between high and low side switching. |
| `driver.max_modulation` | 0.95 |  | Usable fraction of the SVPWM voltage limit (bus voltage / sqrt 3). |
| `driver.current_limit` | 40 | A | Peak phase current limit set in firmware. |
| `driver.current_loop_bw_hz` | 1500 | Hz | Current loop bandwidth. |
| `driver.current_sense_noise` | 0.05 | A | Current sensor noise, rms per sample. |
| `driver.current_sense_lsb` | 0.02 | A | Current per ADC count. |
| `driver.encoder_bits` | 14 |  | Motor-side absolute encoder resolution in bits. |
| `driver.derate_start_c` | 100 | C | Winding temperature where the current limit starts to drop. |
| `driver.derate_end_c` | 120 | C | Winding temperature where the current limit reaches zero. |
| `driver.fet_derate_start_c` | 100 | C | MOSFET temperature where the current limit starts to drop. |
| `driver.fet_derate_end_c` | 125 | C | MOSFET temperature where the current limit reaches zero. |

## gearbox

The gearbox. Friction values are at the output shaft.

| Key | Default | Unit | Meaning |
|---|---|---|---|
| `gearbox.ratio` | 50 |  | Reduction ratio: motor turns per output turn. |
| `gearbox.efficiency` | 0.75 |  | Efficiency at rated load. The loss grows with load: (1 - efficiency) x |input torque|. |
| `gearbox.coulomb` | 2 | Nm | Constant friction torque. Hard to know before building; calibrate fits it. |
| `gearbox.viscous` | 1.5 | Nm s/rad | Friction torque per rad/s of output speed. Calibrate fits it. |
| `gearbox.rated_peak_torque` | 150 | Nm | Repeated peak torque rating from the gearbox datasheet. |
| `gearbox.stribeck_amp` | 0 | Nm | Extra breakaway friction at standstill. Usually left at 0. |
| `gearbox.stribeck_vel` | 0.05 | rad/s | Speed where breakaway friction fades out. |
| `gearbox.position_friction_amp` | 0 | Nm | Friction that varies once per output turn. Usually left at 0. |

## battery

The Li-ion pack, wiring and DC bus.

| Key | Default | Unit | Meaning |
|---|---|---|---|
| `battery.cells_series` | 13 |  | Li-ion cells in series. 13 is about 48 V nominal. |
| `battery.capacity_ah` | 20 | Ah | Pack capacity. |
| `battery.internal_resistance` | 0.08 | ohm | Pack plus wiring resistance. |
| `battery.soc_init` | 0.9 |  | State of charge at the start of a run, 0 to 1. |
| `battery.accepts_regen` | true |  | false for a bench supply that cannot sink current. |
| `battery.bus_capacitance` | 0.00066 | F | Capacitance on the driver board's DC bus. import-kicad sets it. |
| `battery.brake_on_v` | 56 | V | Bus voltage where the brake chopper switches on. |
| `battery.brake_off_v` | 55 | V | Bus voltage where the brake chopper switches off. |
| `battery.brake_resistance` | 10 | ohm | Brake resistor. import-kicad sets it. |
| `battery.overvoltage_v` | 60 | V | The driver faults above this bus voltage. |
| `battery.undervoltage_v` | 39 | V | The driver faults below this bus voltage. |
| `battery.aux_load_w` | 3 | W | Driver logic, encoder and CAN transceiver. |

## thermal

Winding, housing and MOSFET heat paths.

| Key | Default | Unit | Meaning |
|---|---|---|---|
| `thermal.ambient_c` | 30 | C | Air temperature around the joint. |
| `thermal.winding_capacity` | 40 | J/K | Heat capacity of the windings: copper mass in kg x 385. |
| `thermal.housing_capacity` | 350 | J/K | Heat capacity of stator and housing: mass in kg x about 460 for steel or 900 for aluminium. |
| `thermal.r_winding_housing` | 1 | K/W | Thermal resistance from windings to housing. |
| `thermal.r_housing_ambient` | 1.5 | K/W | Thermal resistance from housing to air, including whatever the motor is bolted to. |
| `thermal.fet_capacity` | 5 | J/K | Heat capacity of the MOSFETs and nearby copper. import-kicad sets it. |
| `thermal.r_fet_ambient` | 4 | K/W | Thermal resistance from the MOSFETs to air. import-kicad sets it. |
| `thermal.winding_limit_c` | 120 | C | Highest allowed winding temperature: the insulation class limit minus a margin. |
| `thermal.fet_limit_c` | 125 | C | Highest allowed MOSFET temperature. |

## arm

The link the joint moves. Angle 0 is horizontal, positive lifts.

| Key | Default | Unit | Meaning |
|---|---|---|---|
| `arm.link_length` | 0.5 | m | Joint axis to the payload. |
| `arm.link_mass` | 3 | kg | Link mass, modeled as a uniform rod from the joint to the payload. |
| `arm.payload_mass` | 5 | kg | Heaviest item the arm carries, as a point mass at the link's end. |

## control

Joint position loop running on the driver (or the main computer).

| Key | Default | Unit | Meaning |
|---|---|---|---|
| `control.rate_hz` | 1000 | Hz | Position loop rate. |
| `control.bandwidth_hz` | 8 | Hz | Position loop bandwidth. Higher tracks tighter but needs more current and a stiffer structure. |
| `control.damping_ratio` | 0.8 |  | Position loop damping ratio. |
| `control.vel_filter_hz` | 150 | Hz | Cutoff of the velocity estimate's low-pass filter. |
| `control.use_feedforward` | true |  | Add model-based gravity, inertia and friction torque to the loop output. |
